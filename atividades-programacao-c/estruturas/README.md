# Exercícios de Programação em C — Structs

Resolução de quatro questões sobre estruturas (`struct`) em linguagem C.

1. **questao1.c:** criação dos tipos `Horario`, `Data` e `Compromisso` (com exemplo de uso).
2. **questao2.c:** leitura e armazenamento de nome, idade e endereço em uma estrutura.
3. **questao3.c:** leitura e soma de dois vetores em R³.
4. **questao4.c:** conversão de coordenadas polares para cartesianas usando `cos` e `sin`.

## Compilar e executar

No terminal, dentro desta pasta:

```bash
gcc questao1.c -o questao1
./questao1

gcc questao2.c -o questao2
./questao2

gcc questao3.c -o questao3
./questao3

gcc questao4.c -o questao4 -lm
./questao4
```

No Windows, execute os arquivos gerados com `.\\questao1.exe` (e assim por diante).

**Observação:** o ângulo da questão 4 deve ser informado em radianos.
